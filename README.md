## 1. Executive Summary & Product Vision

Public healthcare networks across India face chronic supply-chain fragilities. The systemic inability to track medicines, patient footfall, medical personnel attendance, bed availability, and resource utilization in real time across large networks of Primary Health Centres (PHCs) leads to sudden stock-outs, inefficient resource allocation, delayed emergency response, and lack of visibility.

**ArogyaGrid AI** has evolved into a next-generation **"AI Healthcare Resilience Operating System"** rather than a traditional management dashboard. It operationalizes a closed-loop resilient healthcare operating philosophy:

$$\text{OBSERVE} \longrightarrow \text{UNDERSTAND} \longrightarrow \text{PREDICT} \longrightarrow \text{SIMULATE} \longrightarrow \text{OPTIMIZE} \longrightarrow \text{RECOMMEND} \longrightarrow \text{HUMAN APPROVAL} \longrightarrow \text{ACT} \longrightarrow \text{LEARN}$$

## 2. Key Architectural Highlights

```
Frontline PHC Edge Nodes (x1,248)
  ├── Local Electronic Health Records (EHR) [Data Stays Local]
  ├── Edge Training (TensorFlow Lite / PyTorch Edge)
  └── Gradient Tensor Sharing with Differential Privacy (DP-SGD, ε=1.20)
             │
             ▼
   Central Parameter Aggregator (FedAvg)
             │
             ▼
   Global Federated Model (Arogya-FedNet-v2.18, 94.6% Accuracy)
             │
   ┌─────────┼──────────────────────┐
   ▼         ▼                      ▼
Demand   Stock-Out             Digital Twin
Forecast  Engine             Simulation Lab
(24h-90d) (Depletion Days)   (What-If Shocks)
   │         │                      │
   └─────────┼──────────────────────┘
             ▼
Integer Linear Programming (ILP) Solver
(Cross-District Lateral Redistribution)
             │
             ▼
Executive Command & Arogya Copilot Interface
(National, State, District, and PHC Administrators)
```

1. **Privacy-Preserving Federated Intelligence**:
   - 1,248 distributed PHC edge nodes train localized models on regional consumption patterns.
   - **Zero Raw Patient PII Leaves the Clinic**; only bounded weight gradients $(\Delta W)$ are shared with the Central Aggregator.
   - Differential Privacy guarantee with privacy budget $\varepsilon = 1.20$ and $\delta = 10^{-5}$.

2. **Healthcare Digital Twin & What-If Simulation Lab**:
   - Graph representation linking State $\rightarrow$ District $\rightarrow$ PHC $\rightarrow$ Beds $\rightarrow$ Personnel $\rightarrow$ Supply Routes.
   - Dynamic simulation of systemic shocks:
     - Patient Demand Surge: $+10\%$ to $+60\%$
     - Supply Disruption: $0\%$ to $80\%$
     - Transport Delay: $0$ to $7$ days
     - Medical Staff Shortage: $0\%$ to $50\%$
   - Instant Before vs. After comparative telemetry.

3. **Explainable AI (XAI) Demand Forecasting**:
   - Forecast horizons: **24 Hours**, **7 Days**, **30 Days**, **90 Days**.
   - Accompanied by $95\%$ Confidence Interval bands.
   - Transparent feature attribution explaining **WHY** demand surged (e.g. $32\%$ historical baseline, $28\%$ viral fever cluster, $21\%$ footfall influx, $8\%$ weather shock).

4. **Automated Cross-District Lateral Redistribution**:
   - Pairs deficit facilities ($<3.5$ days stock remaining) with surplus depots ($>14$ days reserve).
   - Minimizes road transit times across national and state expressways using an Integer Linear Programming solver.
   - Interactive one-click "Approve Redistribution" workflow updating live dispatches and logging immutable audit entries.

5. **Multilingual AI & Voice Command Center**:
   - Seamless language switching: **English**, **Hindi (हिंदी)**, and **Telugu (తెలుగు)**.
   - **Arogya Copilot** parses natural-language prompts like:
     - *"ఏ జిల్లాల్లో మందుల కొరత వచ్చే అవకాశం ఉంది?"*
     - *"किन जिलों में दवाओं की कमी का सबसे अधिक खतरा है?"*
     - *"Simulate a 40% patient surge"*
   - In-browser voice recognition via Web Speech API with fallback.

## 3. Target User Roles & Permissions

The platform provides customized dashboards and workflows for 7 administrative roles:
1. **National Health Administrator**: Pan-India macro resilience index, inter-state corridors, strategic stockpile oversight.
2. **State Health Administrator**: State depot capacities, district-level vulnerability heatmaps, and disaster escalation.
3. **District Health Officer (DHO)**: Block-level primary care clinics, doctor attendance rosters, and local requisition orders.
4. **PHC Administrator**: Clinic bed occupancy, daily patient footfall, batch expiry tracking (FEFO), and local medicine dispensaries.
5. **Supply Chain Manager**: Warehouse utilization %, transit truck telematics, route congestion, and reorder triggers.
6. **Emergency Response Coordinator**: Rapid disaster triage, flood/cyclone/outbreak protocols, field hospital tent allocations.
7. **Data / AI Analyst**: Federated convergence curves, model drift monitoring, differential privacy epsilon tracking.

## 5. Quick Start & Local Execution

### Prerequisites
- Python 3.10+ (Python 3.14 fully supported)
- Node.js v18+ (Node v24 recommended)

---

### Option A: Single URL Execution (Recommended)
Run both frontend and backend seamlessly under a **single unified URL** on port `8000`:

```bash
# 1-Click Launch (Builds frontend if needed and launches server + browser)
python run.py
```

Or on Windows:
```cmd
start.bat
```

Or using npm:
```bash
npm start
```

**Single Unified Access Points:**
- **Web Application (Frontend + Backend)**: [`http://localhost:8000`](http://localhost:8000)
- **Interactive Swagger API Docs**: [`http://localhost:8000/docs`](http://localhost:8000/docs)
- **Live WebSocket Telemetry**: `ws://localhost:8000/ws/telemetry`

> [!TIP]
> Use `python run.py --dev` to run in live development watch mode where frontend TSX/CSS edits automatically recompile and refresh under `http://localhost:8000`.

---

### Option B: Separate Development Terminals (Optional)
If you prefer running the Vite dev server with Hot Module Replacement (HMR) separately:

```bash
# Terminal 1: Backend API
cd backend
python -m pip install fastapi uvicorn pydantic numpy pandas requests
python -m uvicorn main:app --host 127.0.0.1 --port 8000

# Terminal 2: Frontend Dev Server (Proxies API calls to port 8000)
cd frontend
npm install
npm run dev
```
Open your browser at `http://localhost:5173/`.
